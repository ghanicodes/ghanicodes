I'm a MERN Stack developer based in Karachi, Pakistan, with a stronger focus on backend development. I build REST APIs and full-stack web applications using Node.js, Express.js, MongoDB and Mongoose, and I've worked with authentication and authorization using JWT and bcrypt.

I currently work as a MERN Stack & Shopify Developer at TECHCURE. Outside of that, I learn mainly by building practical projects, and the ones listed below are where most of that practice happens.
